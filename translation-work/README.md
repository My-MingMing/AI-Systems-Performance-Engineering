# 《AI Systems Performance Engineering》中文翻译工程

- 源文件保持不变；`unpacked/` 是 EPUB 3 工作副本。
- 默认只翻译读者可见文本和必要的无障碍替代文本，不改图片本身。
- 保留 XHTML 标签、`id`、`href`、`src`、索引锚点、CSS、字体和资源路径。
- 代码、命令、API、产品名、变量与公式原则上保留英文；解释性正文翻译为中文。
- 每次处理一个可核验的段落批次，并在 `progress.md` 中登记，避免中断或上下文限制导致重复工作。
- 技术事实如有疑点，记录在 `errata.md`；仅在有权威依据时修正，并保留说明。
